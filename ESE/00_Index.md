## 6. Answer conventions

### Question text

- Every paper-derived entry starts with a **Question (verbatim)** block. Where the same question appears in several papers with different wording, **each variant is quoted** and all sources are listed under **Asked in**.
- Obvious print/OCR artefacts are corrected silently where they are typographical (e.g. “B. ..” → “Attempt any one of i/ii”). Anything that changes meaning is logged in §7.
- Marks are shown as printed. For F25, the A/B split is 7 + 8 for Q1, Q3 and Q4, and 8 + 7 for Q2.

### PPT-first answers

- Every answer was written after checking the matching deck in [`_ppt_index.md`](_ppt_index.md).
- Definitions, frameworks, stage names, classifications and examples come from the PPTs first.
- Each answer ends with **Reference:** `deck file`, slides X–Y. Slides cited were actually read; image-only slides that could not be read are not cited.
- Where the PPT covers only part of a question, the PPT part comes first, followed by a short **➕ Beyond PPT (textbook/general knowledge):** note.
- No answer is copied from the slides verbatim; terminology is preserved, wording is rewritten.

### Marks decide depth

| Marks | Expected depth |
|---:|---|
| 2–3 | Definition + 2–3 crisp points |
| 5 | Definition → 5–6 points or a 4–6 row table → one example → one-line conclusion |
| 7 | Headings + framework + 6–7 points + example + conclusion |
| 8 | Full structure: definition → framework/diagram → table → example → conclusion |
| 15 (full question) | Diagram + table + example + conclusion (not applicable in these papers; each question is split into 5/7/8-mark parts) |

### Numerical answers

- Only two numericals appear: the fan break-even example (Unit 3 §3.4) and the tiffin-service illustration (Unit 2 §2.3).
- Both were recomputed:
  - Fan: contribution = 2,500 − 1,400 = ₹1,100; BEP = 22,00,000 ÷ 1,100 = **2,000 units/year**.
  - Tiffin: contribution = 80 − 50 = ₹30; BEP = 30,000 ÷ 30 = **1,000 meals/month**.
- Formula is stated before substitution; units are shown.

### Official answers

- F24 and R25 have full synoptic keys; they were used as a starting point, then expanded and checked against the PPTs.
- F25 has only a marking scheme; those answers are fully written from the PPTs and standard theory.
- Where the key and the PPT disagree, the PPT is followed in the main answer and the conflict is logged in §7.
